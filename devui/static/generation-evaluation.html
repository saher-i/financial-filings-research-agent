How these scores work

RAGAS Faithfulness checks whether answer claims follow from the gathered SQL and PDF contexts. RAGAS Response Relevancy asks its judge to generate a question from the answer three times by default, then compares each question's embedding with the original question. Repeated questions can occur because the same prompt is used each time. A metric failure is excluded from that metric's mean and can be retried on its own below. These are official RAGAS implementations, though still model-based estimates.
