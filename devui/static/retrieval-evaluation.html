How these scores work

Official RAGAS Context Precision judges whether each source is useful for the question and supplied expected answer. Context Recall checks which expected claims the sources support. Fireworks supplies the judge. Cited evidence follows citation order. All retrieved evidence includes uncited sources in the order the agent saw them. Because the agent can make several searches, that order is not one global search ranking.
